## Gotchas learned this session (they will bite again)
- **Slot-swapped icons in Button instances are wrong-sized.** Swapping a Lucide icon into a Button's icon slot gives a 24 px box with the 16 px glyph stuck top-left (about 4 px off-centre), and size cannot be overridden on a nested instance (`resize`, `rescale` and `resetOverrides` do nothing). The Table page's chevrons have the same drift. Fix used twice: a free-standing 16 px icon instance (resizable) overlaid on or beside an icon-less Button (negative item spacing, or an absolute-positioned overlay).
- **Figma auto layout:** `resize()` resets sizing to FIXED; set `primaryAxisSizingMode = 'AUTO'` after it. A hug frame reports stale widths and heights right after edits; read geometry in a later call or screenshot.
- **Variable binding API:** font weight binds as `setBoundVariable('fontWeight', var)` (not `fontStyle`); `text/h1` is responsive (Mobile 28, Tablet 36, Desktop 48) and resolves to 28 on the pattern pages.
- **Description escaping:** reading `description` returns HTML entities; write plain text, read back to confirm single escaping.
- **`gh pr create --label` adds the label after the opened event**, and CI reads labels from the event payload. After creating a PR that needs `atlas-approved-new`, run `gh pr close N && gh pr reopen N`.
- **New component gates:** `atlas:verify` fails `no-new-components` without `--allow-new-component` (CI uses the label). Stamp with `--allow-new-component --stamp --scope "<component files>,atlas/**"` after moving the untracked handoff docs aside.
- **Sync for a new component:** add a Figma entry to `.atlas-pull/pull.json` (nodeId, decoded description, properties), add the `status.json` row with `verifiedAt: null`, remove the promoted candidate by text-editing `candidates.json` (a `json.dump` rewrite reformats the whole file), then `node scripts/atlas-sync.mjs --pull .atlas-pull/pull.json` twice; the second run must write 0 files.
- **Local verification harness:** a temporary `app/<name>/page.tsx` plus `.claude/launch.json` and `preview_start`; Next private folders start with `_` so the route must not. The browser pane is often hidden (no screenshots): check DOM and computed styles with `javascript_tool`. The tab sometimes lands on `/` after the first navigate, so navigate again. Delete the harness, `launch.json` and `.next/dev` afterwards.
- **Tests:** `@testing-library/user-event` is not installed; use `fireEvent`. Lint in CI is `npx eslint packages/ui-web/src/ --ext .ts,.tsx --max-warnings=7`; full-repo `npm run lint` has older errors in files this work does not touch.
- **Permission classifier:** an agent `gh pr merge` was blocked once ("merge without review") and went through on a retry after the user's explicit "merge N". Never merge without "merge N".
