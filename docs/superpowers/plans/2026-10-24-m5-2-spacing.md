# M5.2 — Semantic spacing tier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add nine semantic spacing roles, then move every component use whose meaning fits onto them. Not a single pixel may move.

**Architecture:** This follows the M5.1 radius method (plan `2026-10-23-m5-1-radius.md`).
- **PR-0** creates the nine roles in Figma `Atlas/Semantic`, re-syncs the variable table, and adds the roles to `atlas.tokens.css` as exact `var()` aliases. It also re-aliases four component tokens in Figma and code.
- **PR-1** rewrites the 139 matching component uses with a line-exact script. It adds a token-lint ratchet, `semantic-spacing`: inside the spacing properties, a primitive spacing step fails unless an allowlist entry gives a reason and the exact count.

**Tech Stack:** CSS custom properties · `packages/governance/token-lint.mjs` · `scripts/lib/token-rules.mjs` (pure, `node:test`) · JSON Schema 2020-12 (`scripts/lib/schemas.mjs`) · Figma MCP `use_figma` · Playwright visual job (CI).

## Global Constraints

- **Kind A: value-identical alias migration (roadmap M5).** The expected visual diff is **exactly zero changed baselines**. A non-zero diff is a bug, never a baseline to accept. If any step needs a value change, the stage stops and re-opens as Kind B.
- Aliases must be value-identical, never "rounded to the nearest scale step" (R8).
- **Role set (owner, 2026-10-24, chosen by meaning):**

| Role (Figma `Atlas/Semantic`) | CSS | Aliases | Meaning |
|---|---|---|---|
| `spacing-focus-offset` | `--atlas-spacing-focus-offset` | `spacing/0_5` (2px) | `outline-offset` of a focus ring |
| `spacing-item-gap` | `--atlas-spacing-item-gap` | `spacing/1` (4px) | between sibling items of one tight group (tabs, pages, links, chips) |
| `spacing-text-gap` | `--atlas-spacing-text-gap` | `spacing/1` (4px) | title → description inside one text group |
| `spacing-overlay-offset` | `--atlas-spacing-overlay-offset` | `spacing/1` (4px) | distance from a trigger to its popover |
| `spacing-control-gap` | `--atlas-spacing-control-gap` | `spacing/2` (8px) | between the parts of one row or control |
| `spacing-item-padding` | `--atlas-spacing-item-padding` | `spacing/2` (8px) | padding of a menu/list item or a table cell |
| `spacing-section-gap` | `--atlas-spacing-section-gap` | `spacing/3` (12px) | between the parts and blocks of a surface's header, body and footer |
| `spacing-surface-padding` | `--atlas-spacing-surface-padding` | `spacing/4` (16px) | padding of a surface |
| `spacing-surface-padding-lg` | `--atlas-spacing-surface-padding-lg` | `spacing/6` (24px) | padding of a roomy surface (modal family default, chart body, large card) |

- **Rule scope (owner, 2026-10-24):** `semantic-spacing` reads only spacing properties. These are `padding*`, `margin*`, `gap`/`row-gap`/`column-gap`, `inset*`/`top`/`right`/`bottom`/`left` and `outline-offset`. It also reads custom properties named for spacing (`--_pad`, `--code-pad`, `--_px`, `--_item-gap`…, matching `(padding|pad|gap|margin|offset|px)\b`) and the component tokens in `atlas.tokens.css` whose names match the same pattern. **Dimension uses are out of scope by rule, not by allowlist.** That covers width, height, `*-size`, avatar, box and thumb sizes, button heights, transforms and `calc()` sizes: about 226 uses, left to a later size family. The layout tokens `--atlas-gutter-*` and `--atlas-margin-*` are already a semantic tier and are excluded.
- Figma first: the variables exist in Figma and are synced before the CSS adds them. Figma wins on any disagreement.
- One family across all components per PR, never one component across families. If PR-1 is too large to review, split it by tier (primitives · compositions · patterns+layouts), still spacing only.
- No new component, and no token beyond the nine roles. `atlas/` is regenerated, never hand-edited, **except** `atlas/state/decisions.json` and `candidates.json`, which are appended.
- A use moves to a role only when the role's *meaning* fits. A matching value is not enough. A composed value (`calc()`, `min()`) always stays primitive.

The classifier, `m52-classify.mjs`, reads every declaration `([-\w]+)\s*:\s*([^;{}]+)` in comment-stripped CSS. It keeps the in-scope properties, resolves the selector as the text before the nearest open `{`, and matches each use against `RULES`. It must report **139 role uses, 188 primitive, 0 unused rules**. A rule that matches nothing fails the run, and so does any count change.

```js
// ─── semantic-spacing (M5.2) ─────────────────────────────────────────────────
// Inside a spacing property (padding, margin, gap, inset, outline-offset, or a custom property named for
// spacing), component code names a spacing ROLE. A primitive step is legal only where
// packages/governance/token-primitives.allow.json gives a reason and the exact count per file. Width,
// height and other dimension uses are out of scope: they belong to a later size family (DEC-087).
const SPACING_PROP = /^(?:padding|margin|gap|row-gap|column-gap|inset|top|right|bottom|left|outline-offset)(?:-|$)|^--(?!atlas-spacing-)[\w-]*(?:padding|pad|gap|margin|offset|px)\b/
const SPACING_STEP = /var\(\s*(--atlas-spacing-(?:0|px|0_5|1|1_5|2|3|4|5|6|8|9|10|12|16))\s*\)/g
const SPACING_ANY = /var\(\s*--atlas-spacing-[\w-]+\s*\)/g
const DECL = /([-\w]+)\s*:\s*([^;{}]+)/g

export function semanticSpacingViolations(files, allow) {
  const violations = []
  const used = new Set()
  let inspected = 0
  for (const { file, src } of files) {
    const s = stripComments(src)
    const byToken = new Map()
    for (const d of s.matchAll(DECL)) {
      if (!SPACING_PROP.test(d[1])) continue
      const at = d.index + d[0].length - d[2].length
      inspected += (d[2].match(SPACING_ANY) ?? []).length
      for (const m of d[2].matchAll(SPACING_STEP)) {
        if (!byToken.has(m[1])) byToken.set(m[1], [])
        byToken.get(m[1]).push(lineOf(s, at + m.index))
      }
    }
    for (const [token, lines] of byToken) {
      const i = allow.findIndex((a) => a.family === "spacing" && a.file === file && a.token === token)
      if (i === -1) {
        lines.forEach((line) => violations.push({ file, line, text: `${token} — use a spacing role (focus-offset|item-gap|text-gap|overlay-offset|control-gap|item-padding|section-gap|surface-padding|surface-padding-lg), or list it with a reason in packages/governance/token-primitives.allow.json` }))
        continue
      }
      used.add(i)
      if (allow[i].count !== lines.length) violations.push({ file, line: lines[0], text: `${token}: ${lines.length} uses, allowlist says ${allow[i].count} — update the count or use a role` })
    }
  }
  allow.forEach((a, i) => {
    if (a.family === "spacing" && !used.has(i)) violations.push({ file: a.file, line: 0, text: `stale allowlist entry ${a.token} — no such use; remove it from packages/governance/token-primitives.allow.json` })
  })
  return { violations, inspected }
}
```
