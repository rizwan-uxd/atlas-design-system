# M5.4 — Semantic motion tier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add six motion roles. Each one pairs a duration with an easing, named for what the motion does. Move every component transition and animation whose intent fits onto a role, and point the JS motion presets at the same roles. Every timing change is listed below before any code.

**Architecture:**
- **PR-0** adds the 12 role tokens `--atlas-motion-<role>-duration|easing` as aliases of the existing duration and easing tokens, plus 12 Figma documentation variables. Nothing consumes them yet.
- **PR-1:**
  - rewrites the 101 mapped uses
  - points `motion-presets.ts` at the roles
  - teaches `reduced-motion-required` to see role tokens
  - adds the ratchet `semantic-motion`

**Tech Stack:** CSS custom properties · `packages/ui-web/src/motion/` (`motion-tokens.ts`, `motion-presets.ts`) · token-lint (`scripts/lib/token-rules.mjs`) · vitest (`packages/ui-web/tests/motion.test.ts`) · Figma MCP `use_figma` (variables only) · Playwright.

## Global Constraints

- **Kind B: value-changing migration (roadmap M5).** The changes are timing, not layout.
  - The visual tests run with `animations: "disabled"` (`playwright.config.ts`), so the expected screenshot diff is **zero changed baselines**. A changed baseline is a bug.
  - The listed timing changes are reviewed in this plan and DEC-089, and proven by a computed-style diff of `transition-*` and `animation-*`.
  - `prefers-reduced-motion` and dark mode are re-checked (roadmap: required for M5.4).
- **Role set (owner, 2026-10-24):**

| Role | Duration | Easing | Meaning |
|---|---|---|---|
| `motion-state` | `fast` 120ms | `standard` | hover, press and focus: colour, border, shadow, opacity, small state transforms (chevron rotate, dot scale) |
| `motion-move` | `base` 200ms | `emphasized` | an element moving or resizing: indicators, thumbs, panel and bar size, hide-on-scroll |
| `motion-enter` | `base` 200ms | `emphasized` | dialog, drawer, sheet, tab panel, alert, toast entering |
| `motion-exit` | `base` 200ms | `exit` | the same leaving |
| `motion-enter-quick` | `fast` 120ms | `standard` | backdrops, tooltip and small popovers appearing |
| `motion-exit-quick` | `fast` 120ms | `exit` | the same disappearing, and toast swipe-out |

- **CSS names:** `--atlas-motion-<role>-duration` and `--atlas-motion-<role>-easing`, 12 tokens. Each is one `var()` alias of `--atlas-duration-*` or `--atlas-easing-*`.
- **Stays primitive** (allowlisted with a reason):
  - loops on their own period: spin, pulse, indeterminate slide, caret blink
  - the Checkbox mark draw-in
  - Slider and ScrollProgress, which follow the pointer or the scroll
- **Figma:** motion variables are documentation only. Figma cannot bind a variable to prototype timing, which is why the primitives have empty scopes. The 12 role variables go in `Atlas/Semantic`, aliasing the primitives in Light and Dark, with empty scopes and WEB syntax. There are no text styles or layers to apply them to. Gate 2 approves the variables and the listed timing changes.
- **Motion tokens are CSS-first (AGENTS §11).** `motion-tokens.ts` reads the CSS, and `motion.test.ts` keeps `defaultMotionTokens` equal to it. Components never write a literal.
- **Reduced motion must not regress.** `reduced-motion-required` today detects animated files by `--atlas-duration-*`. A file that ends up with only role tokens would silently drop out of the check, so the rule must also see `--atlas-motion-*`. That change lands before the migration.
- Branch from `main` after #113 (M5.3) merges. One family per PR. No new component. No token beyond the 12.

import { readFileSync } from "node:fs"
import { resolve } from "node:path"
import { describe, expect, it } from "vitest"

const css = readFileSync(resolve(__dirname, "../../tokens/atlas.tokens.css"), "utf8")
const ROLES = {

  exit: ["base", "exit"], "enter-quick": ["fast", "standard"], "exit-quick": ["fast", "exit"],

      expect(decls(`--atlas-motion-${role}-easing`)).toEqual([`var(--atlas-easing-${e})`])
    })
  }
})

### Task 3: Reduced-motion detection, then the `semantic-motion` ratchet

**Files:** `scripts/lib/token-rules.mjs` (`reducedMotionMissing`, new `semanticMotionViolations`) · `packages/governance/token-lint.mjs` (the `animated` filter on line ~276 and rule 14) · schema `family` enum adds `"motion"` and `token` pattern adds `duration|easing` · `scripts/tests/token-rules.test.mjs`

- [ ] **Step 1: Write the failing tests**

```js
test("reduced motion: a file animating only with motion roles still needs a reduced-motion block", () => {
  assert.equal(reducedMotionMissing(".a { transition: color var(--atlas-motion-state-duration) var(--atlas-motion-state-easing); }"), true)
  assert.equal(reducedMotionMissing(".a { transition: color var(--atlas-motion-state-duration); } @media (prefers-reduced-motion: reduce) { .a { transition: none; } }"), false)
})

test("semantic motion: a role passes; a primitive duration or easing fails", () => {
  const ok = ".a { transition: color var(--atlas-motion-state-duration) var(--atlas-motion-state-easing); }"
  assert.deepEqual(semanticMotionViolations([{ file: F, src: ok }], []).violations, [])
  const { violations } = semanticMotionViolations([{ file: F, src: ".a {\n  animation: x var(--atlas-duration-base) var(--atlas-easing-exit);\n}" }], [])
  assert.deepEqual(violations.map((v) => v.line), [2, 2])
  assert.match(violations[0].text, /motion role/)
})

test("semantic motion: an instant duration inside a reduced-motion block is legal", () => {
  const src = "@media (prefers-reduced-motion: reduce) { .a { transition-duration: var(--atlas-duration-instant); } }"
  assert.deepEqual(semanticMotionViolations([{ file: F, src }], []).violations, [])
})

test("semantic motion: exact count per file and token; a stale entry fails", () => {
  const allow = [{ family: "motion", file: F, token: "--atlas-duration-spin", count: 1, reason: "spinner loop" }]
  const one = ".s { animation: spin var(--atlas-duration-spin) linear infinite; }"
  assert.deepEqual(semanticMotionViolations([{ file: F, src: one }], allow).violations, [])
  assert.match(semanticMotionViolations([{ file: F, src: ".a {}" }], allow).violations[0].text, /stale allowlist entry/)
})
```
