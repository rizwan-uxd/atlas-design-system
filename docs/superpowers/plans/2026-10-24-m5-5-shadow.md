## Global Constraints

- **Kind B: value-changing migration (roadmap M5).** Two listed changes (below), both approved by the owner on 2026-10-24. Neither one is rendered at rest in a screenshot (the Chart tooltip only shows on hover; `NavBarHeader` is not in the sandbox or the runtime demo), so the expected screenshot diff is **zero changed baselines**, and no `visual-baseline.yml` PR is expected. A changed baseline is a bug. The listed changes are proven by the CSS diff and by computed `box-shadow` dumps.
- **Dark mode is re-checked (roadmap: required for M5.5).** Shadows are the only non-colour family with a dark override (`atlas.tokens.css:388-391`). A role declared only on `:root` would resolve against the light value and be inherited unchanged into a `[data-theme="dark"]` or `.dark` **subtree**, silently dropping the override. So the roles are declared in a `:root, [data-theme="dark"], .dark` block, like the component-token block, and the dumps include a dark-subtree mode.
- **Role set (owner, 2026-10-24):**

| Role | Alias of | Meaning |
|---|---|---|
| `--atlas-shadow-raised` | `--atlas-shadow-sm` | a part lifted slightly above its track or container, in normal flow |
| `--atlas-shadow-surface` | `--atlas-shadow-md` | a surface resting above the page |
| `--atlas-shadow-popover` | `--atlas-shadow-md` | a layer anchored to the thing that opened it |
| `--atlas-shadow-floating` | `--atlas-shadow-lg` | unanchored, non-modal chrome floating over content |
| `--atlas-shadow-modal` | `--atlas-shadow-xl` | a modal layer above the scrim |

- **Card component tokens stay** and point at roles: `--atlas-card-elevated-shadow: var(--atlas-shadow-surface)`, `--atlas-card-elevated-shadow-hover: var(--atlas-shadow-floating)` (both value-identical).
- **Figma approach (owner, 2026-10-24): hybrid.** Effect styles hold the shadow, each layer's colour is bound to a COLOR variable with Light and Dark modes, geometry is static in the style (it is identical in both modes). Figma has no composite shadow variable, and plain styles have no modes.
- **Shadow layer colours (5 variables, de-duplicated from the 7 CSS layers):**

| Figma variable (`Atlas/Semantic`) | Light | Dark | CSS layers using it |
|---|---|---|---|
| `shadow/color-1` | black 5% | black 40% | sm |
| `shadow/color-2` | black 6% | black 45% | md layer 1 |
| `shadow/color-3` | black 8% | black 50% | md layer 2, lg layer 1 |
| `shadow/color-4` | black 10% | black 55% | lg layer 2, xl layer 1 |
| `shadow/color-5` | black 14% | black 60% | xl layer 2 |

  These have **no `codeSyntax.WEB`**: the code keeps whole shadows, so they are Figma-only and the table reports them as `unpublished` (never drift). Scope `["EFFECT_COLOR"]`.
- **Effect styles (11), each layer `DROP_SHADOW`, offset x 0, blend NORMAL, `showShadowBehindNode: false`:**

| Style | Layers (y / blur / spread / colour) | Covers CSS token |
|---|---|---|
| `Shadow/sm`, `Shadow/raised` | 1/2/0 color-1 | `--atlas-shadow-sm`, `--atlas-shadow-raised` |
| `Shadow/md`, `Shadow/surface`, `Shadow/popover`, `Card/elevated-shadow` | 2/4/-1 color-2 · 4/8/-2 color-3 | `--atlas-shadow-md`, `-surface`, `-popover`, `--atlas-card-elevated-shadow` |
| `Shadow/lg`, `Shadow/floating`, `Card/elevated-shadow-hover` | 4/8/-2 color-3 · 12/24/-4 color-4 | `--atlas-shadow-lg`, `-floating`, `--atlas-card-elevated-shadow-hover` |
| `Shadow/xl`, `Shadow/modal` | 8/16/-4 color-4 · 24/48/-8 color-5 | `--atlas-shadow-xl`, `--atlas-shadow-modal` |

  Figma styles cannot reference other styles, so role styles repeat their size's layers. Layer order does not change the result: every layer is black, and alpha compositing of one colour is commutative.
- **Style ↔ token convention:** a style covers `--atlas-` + its name lowercased with `/` → `-` (`Shadow/md` → `--atlas-shadow-md`, `Card/elevated-shadow` → `--atlas-card-elevated-shadow`). A style whose name maps to no declared token is `missingInCode`.
- **Figma wins.** If the Task 1 audit finds a Figma component shadow whose values differ from the code value it maps to, stop and report it; the owner decides before any style is applied.
- **Out of scope:** `packages/ui-native` (its tokens file emits no shadows and `shadowHelper` is separate, so no `atlas-native-thaw` label); `app/prototypes/_shared/PhoneFrame.tsx`, which keeps `--atlas-shadow-xl` (a valid size token; the lint rule reads component CSS only); DISC-107's other 9 tokens (dialog widths, safe-area, `neutral-50`).

```js
// ─── semantic-shadow (M5.5) ──────────────────────────────────────────────────
// Component shadows name a shadow ROLE (--atlas-shadow-raised|surface|popover|floating|modal) or a
// component token. A size step is legal only where packages/governance/token-primitives.allow.json
// gives a reason and the exact count per file (DEC-090).
const SHADOW_STEP = /var\(\s*(--atlas-shadow-(?:sm|md|lg|xl))\s*\)/g
const SHADOW_ANY = /var\(\s*--atlas-[\w-]*shadow[\w-]*\s*\)/g

export function semanticShadowViolations(files, allow) {
  const violations = []
  const used = new Set()
  let inspected = 0
  for (const { file, src } of files) {
    const s = stripComments(src)
    inspected += (s.match(SHADOW_ANY) ?? []).length
    const byToken = new Map()
    for (const m of s.matchAll(SHADOW_STEP)) {
      if (!byToken.has(m[1])) byToken.set(m[1], [])
      byToken.get(m[1]).push(lineOf(s, m.index))
    }
    for (const [token, lines] of byToken) {
      const i = allow.findIndex((a) => a.family === "shadow" && a.file === file && a.token === token)
      if (i === -1) {
        lines.forEach((line) => violations.push({ file, line, text: `${token} — use a shadow role (--atlas-shadow-raised|surface|popover|floating|modal), or list it with a reason in packages/governance/token-primitives.allow.json` }))
        continue
      }
      used.add(i)
      if (allow[i].count !== lines.length) violations.push({ file, line: lines[0], text: `${token}: ${lines.length} uses, allowlist says ${allow[i].count} — update the count or use a role` })
    }
  }
  allow.forEach((a, i) => {
    if (a.family === "shadow" && !used.has(i)) violations.push({ file: a.file, line: 0, text: `stale allowlist entry ${a.token} — no such use; remove it from packages/governance/token-primitives.allow.json` })
  })
  return { violations, inspected }
}
```
