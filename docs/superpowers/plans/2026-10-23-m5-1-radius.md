# M5.1 — Semantic radius tier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first non-colour semantic token family, four radius roles. Then move every component use whose role fits onto them. Not a single pixel may move.

**Architecture:** PR-0 creates `radius/item|control|surface|pill` in Figma `Atlas/Semantic` (Light and Dark both alias the same primitive). It re-syncs the variable table and adds the roles to `atlas.tokens.css` as exact `var()` aliases. PR-1 rewrites the component CSS and component-token aliases whose role fits, and adds a token-lint ratchet, `semantic-radius`. Under the ratchet a primitive radius in component code fails unless an allowlist entry gives its reason and exact count.

**Tech Stack:** CSS custom properties · `packages/governance/token-lint.mjs` · `scripts/lib/token-rules.mjs` (pure, `node:test`) · JSON Schema 2020-12 (`scripts/lib/schemas.mjs`) · Figma MCP `use_figma` · Playwright visual job (CI).

## Global Constraints

- **Kind A — value-identical alias migration (roadmap M5).** The expected visual diff is **exactly zero changed baselines**. A non-zero diff is a bug, never a baseline to accept. If any step needs a value change, the stage stops and re-opens as Kind B.
- Aliases must be value-identical, never "rounded to the nearest scale step" (R8).
- Role set (user, 2026-10-23): `radius/item = radius/sm (4)`, `radius/control = radius/md (8)`, `radius/surface = radius/lg (12)`, `radius/pill = radius/full (9999)`. `radius/none`, `radius/xl`, `radius/2xl` stay primitive.
- CSS names: `--atlas-radius-item`, `--atlas-radius-control`, `--atlas-radius-surface`, `--atlas-radius-pill`.
- Figma first: the variables exist in Figma and are synced before the CSS adds them. Figma wins on any disagreement.
- One family across all components per PR, never one component across families.
- No new component. No token beyond the four roles. `atlas/` is regenerated, never hand-edited, **except** `atlas/state/decisions.json` and `candidates.json`, which are appended per the atlas-component companions table.
- A use moves to a role only when the role's *meaning* fits. Matching the value is not enough. A use whose value matches but whose meaning does not stays primitive, gets an allowlist reason, and is logged as a candidate role.

```js
// ─── semantic-radius (M5.1) ──────────────────────────────────────────────────
// Component code names a radius ROLE (--atlas-radius-item|control|surface|pill). A primitive step is
// legal only where packages/governance/token-primitives.allow.json gives a reason and the exact count
// per file, so a new primitive use fails and a migrated one leaves a stale count that fails too.
const RADIUS_PRIMITIVE = /var\(\s*(--atlas-radius-(?:none|base|sm|md|lg|xl|2xl|full))\s*\)/g

export function semanticRadiusViolations(files, allow) {
  const violations = []
  const used = new Set()
  let inspected = 0
  for (const { file, src } of files) {
    const s = stripComments(src)
    inspected += (s.match(/var\(\s*--atlas-radius-[\w-]+\s*\)/g) ?? []).length
    const byToken = new Map()
    for (const m of s.matchAll(RADIUS_PRIMITIVE)) {
      if (!byToken.has(m[1])) byToken.set(m[1], [])
      byToken.get(m[1]).push(lineOf(s, m.index))
    }
    for (const [token, lines] of byToken) {
      const i = allow.findIndex((a) => a.family === "radius" && a.file === file && a.token === token)
      if (i === -1) { lines.forEach((line) => violations.push({ file, line, text: `${token} — use a radius role (item|control|surface|pill), or list it with a reason in packages/governance/token-primitives.allow.json` })); continue }
      used.add(i)
      if (allow[i].count !== lines.length) violations.push({ file, line: lines[0], text: `${token}: ${lines.length} uses, allowlist says ${allow[i].count} — update the count or use a role` })
    }
  }
  allow.forEach((a, i) => {
    if (a.family === "radius" && !used.has(i)) violations.push({ file: a.file, line: 0, text: `stale allowlist entry ${a.token} — no such use; remove it from packages/governance/token-primitives.allow.json` })
  })
  return { violations, inspected }
}
```

(Entries carry `family: "radius"` so M5.2 adds `"spacing"` to the same file.)
