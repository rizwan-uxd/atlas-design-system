## Gotchas learned (they will bite again)
- **Donut ring in Figma, inner radius is a fraction of the RADIUS, not the diameter.** For a 48 px ring with a 4 px band, `innerRadius = (24 - 4) / 24 = 0.833`. An ellipse with `arcData.innerRadius` 0 strokes a pie wedge: draw the ring as a filled donut sector, `arcData = { startingAngle: -PI/2, endingAngle: -PI/2 + 2*PI*fraction, innerRadius: (r - thickness) / r }`, over a full-circle track, both absolutely positioned in a centred auto-layout frame.
- **Figma geometry is stale in the same call as an edit.** Read sizes and positions in a **later** call; `resize()` resets sizing to FIXED (set `primaryAxisSizingMode = 'AUTO'` after it); `layoutSizingHorizontal = 'FILL'` only after `appendChild`; after `setExplicitVariableModeForCollection` an instance can stay at (0, 0): `frame.appendChild(child)` again and read later.
- **Native components are checked differently:** they are not in the sync snapshot and have no Code Connect, contract or test, so a native task's checks are tsc, `atlas:verify --allow-new-component` and a manual or harness check.
- **Radix `Slot` and extra children:** `Slot` needs exactly one element child; a component that renders icons around `{children}` must wrap the child in `Slottable` (Button `asChild`, DEC-073).
- **Fragments change `container.firstElementChild`:** Stepper returns a summary and the `<ol>`, so tests select `container.querySelector("ol")`.
- **Sync restamps every file unless `pulledAt` is the old stamp.** Set `pulledAt` to the existing `syncedAt` (all metadata share one; it was `2026-10-10T17:05:52.269Z`) and the sync writes only what changed, then 0 on the second run. A brand-new component needs its description in the pull file or the sync refuses ("component doc is missing") even under `--check`.
- **Radix Dialog mounts its portal one pass late.** State that reads the rows by DOM must live in a component rendered *inside* `DialogContent` (the CommandMenu highlighted row).
- **A new component needs `--allow-new-component`** on `atlas:verify`, and `atlas:verify` fails a `<div onClick>` without `role` and `tabIndex`.
- **Promoting a candidate can break a sync test.** `scripts/tests/atlas-sync.test.mjs:182` uses an unbuilt candidate as its "component that does not exist" (it is `Marquee` now). Run `npm run test:scripts` before pushing a promotion; only the CI step `Script tests` covers it otherwise.
- **Slots on a component (Sheet pattern):** `component.createSlot()` makes a SLOT layer and a set-level SLOT property (`figma.createSlot` does not exist). Renaming the layer renames the property. For other variants create the slot, set `componentPropertyReferences = { visible, slotContentId }` to the first variant's keys, and delete every SLOT property you do not keep (`set.deleteComponentProperty`). An instance keeps the component's fixed height.
- **No property bindings inside a nested instance's slot** ("instance sublayer" error). Use a **variant property** (Leading icon off|on, Interaction), not a boolean or instance swap.
- **Adding a variant property with a twin set (StatCard Sparkline, DEC-069):** rename the existing variants first, clone the sources, change the children, `set.appendChild(clone)` and rename. Clones render blank until `resizeWithoutConstraints` grows the set; move the Review frame down and check overlaps. `variant.clone()` lands on the page, not in the set; reach a slot after moving by path (`clone.children[0].children`). Set bounds do not grow when variants are added.
- **`atlas:verify --stamp` fails the scope check on unrelated dirty files:** list them in `--scope` for the stamp run, then commit only the component's files with a pathspec.
- **Dark-mode `*-muted` tokens are slabs** (success-muted `#007033`, danger-muted `#ad0016`); use `*-subtle` for soft washes.
- **Sync recipe in a fresh session** (no `.atlas-pull/`): build `pull.json` from `atlas/metadata/*.json` (`nodeId` from `figmaNodeId`, `properties` from `figmaProperties`, `componentProperties` from `figmaComponentProperties`) plus the patched component's `description`, taken from `atlas/<Name>.md` between `# <Name>` and `<!-- BEGIN:generated-structure -->` with the Figma edit applied. First run `--check` with the unchanged description: it must list only that component. Then run the real sync twice; the second must write 0 files.
- **New component PR:** `atlas:verify --allow-new-component`, final run adds `--stamp`. CI fails `no-new-components` until the PR carries the `atlas-approved-new` label: the label is the owner's gate, add it only when told ("add the label"), with `issue_write` (`method: update`, `labels`) because `create_pull_request` cannot set labels. The `labeled` event starts a second CI run; the first run's Atlas Verify stays red and is superseded. Merge with the label on and the second run green.
- **Code Connect parse:** an unsupported expression (a conditional such as `clickable ? () => {} : undefined`) makes the file print a `❌`. `main` has 8 such files and the job still exits 0, but do not add a ninth: map with `figma.enum` instead.
- **SVG props:** `React.SVGAttributes` already has `values: string`, so a `values: number[]` prop needs `Omit<..., "values">`.
- **Hand-written state rows** (no `detectedBy`) in `atlas/state/discrepancies.json` survive sync. Edit `atlas/state/*.json` as text: a `json.dump` round trip reformats the whole file (a 98-line diff once). New decision entries use 6-space keys inside a 4-space `{`.
- **Slot-swapped icons in Button instances are wrong-sized** (24 px box, 16 px glyph off-centre). Use a free-standing 16 px icon instance; set a Button's icon through the `Icon#` property with a component id and check the property value, because a same-call screenshot shows the old glyph.
- **Description escaping:** reading a Figma `description` returns HTML entities; write plain text and read back to confirm single escaping. Never read, edit and write it straight back (double-escapes).
- **Screenshots:** `get_screenshot` URLs are blocked by the sandbox proxy: pass `enableBase64Response: true`. A node screenshot clips effects outside the node (the focus ring).
- **Figma native sets from web sets:** `webSet.clone()`, `mobilePage.appendChild(clone)`, rename, position, write the description; instances inside a cloned set still point at the web components, so `swapComponent` them to the mobile set.
