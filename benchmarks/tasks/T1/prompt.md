Build a new prototype flow called "send-money" — a Wise-style Send Money flow in a mobile frame, like the other prototypes in this project.

Steps:
1. Recipient — search field plus a list of recent recipients (name, masked account, currency). Tapping one selects it.
2. Amount — "You send" and "Recipient gets" fields with currency labels, a fee breakdown (fee, rate, total), and an arrival-time notice. Continue stays disabled until the amount is valid.
3. Review — summary of recipient, amounts and fee. "Confirm and send" opens a confirmation dialog; confirming shows a success state.

Use the Atlas design system. Register the flow so it appears on the prototypes index. When you're done, make sure it passes the token lint.
