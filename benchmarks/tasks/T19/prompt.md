Build a new prototype screen called "notifications" — a mobile Notifications screen, like the other prototypes in this project.

It needs:
- A page title and one way to mark everything as read.
- A list of 6 sample notifications (for example a mention, an approval request, a failed payment, a comment), each saying what happened, where and when, and clearly unread or read.
- Two views of the list: all notifications, and only the unread ones.
- On each notification, a way to mark it as read or unread; the approval request also has an Approve action.
- A loading state, an empty state for when there is nothing to show, and an error state for when the list fails to load, with a way to try again.

Use the Atlas design system. Register it so it appears on the prototypes index. When you're done, make sure it passes the token lint.
