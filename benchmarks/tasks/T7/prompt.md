Build a new prototype screen called "dashboard-summary" — a mobile account dashboard, like the other prototypes in this project.

It needs:
- A page title and a short greeting.
- Four summary figures (Balance, Income, Spending, Savings), each with its value and a change since last month (up or down).

- A loading state and a failed-to-load state with a way to retry. Provide a way to switch between loaded, loading and failed so each can be reviewed.
