Build a new prototype flow called "onboarding" — a 3-step mobile onboarding flow, like the other prototypes in this project.

Steps:
1. Profile — full name (required) and role (choose one from a short list).
2. Preferences — turn on or off email and push notifications, and pick a plan: Free, Pro or Team. This step can be skipped.
3. Done — a short confirmation with a button to continue to the app.

Show progress through the steps. Every step except the first has a way back. Show a clear message when a required field is missing or invalid.

Use the Atlas design system. Register the flow so it appears on the prototypes index. When you're done, make sure it passes the token lint.
